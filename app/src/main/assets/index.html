关于本 WebUI

📱 本界面为 CoreGate 的 APK 内置图形化控制台（WebUI），通过底部悬浮导航栏在四个页面间切换：🔒锁核（运行状态 / 核心可视化 / 锁核建议）、🎮策略（游戏包名 / 录屏相机 / 充电与检测间隔）、⚙️限频（日常限频与生效实况）、⚙️设置（诊断 / 测试 / 清理）。
所有配置写入 /data/adb/CoreGate/config.json，点底部「保存配置」后约 5 秒内自动生效，无需重启。
全部修改仅作用于 sysfs 运行时，重启即还原，不写入任何系统分区，零残留、完全可逆。作者 zimky。

⚙️ 日常限频（进阶省电）
启用日常限频
默认关。开启后把 CPU 大小核与 GPU 的最高频锁到保守档位，明显更省电，但重负载会变慢。游戏在列表内时自动解除。
小核簇 ≤ 2266 MHz · 大核簇 ≤ 1651 MHz · GPU ≤ 500 MHz（功耗档 13）。 仅在当前频率偏离目标时才写入，避免与厂商调度反复拉扯。 ⚠️ 若发现日常卡顿或游戏掉帧，请关闭本项。
限频生效实况
直接读取内核节点当前值，与目标上限逐项比对。「已锁定」= 内核实际值已等于目标；「已放开」= 处于游戏/恢复状态。
